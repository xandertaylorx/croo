Bring your own

Use the plan you already pay for.

Croo doesn’t resell tokens. Sign in once with the Claude or Codex command line and Croo runs it for you, with its tools, its limits and your plan. Prefer a key, or no internet at all? That works too, and you can switch models mid-chat.

  • Claude subscriptionPro, Max or Team
    claude auth login
  • ChatGPT subscriptionPlus, Pro, Business or Edu
    codex login
  • API keysClaude, OpenAI, Gemini, OpenRouter, Groq, DeepSeek, Mistral, xAI, Together
    paste a key
  • On your MacOllama, LM Studio, llama.cpp, vLLM, or a built-in download
    no key, offline

Croo never sees your subscription login. Keys are encrypted in your keychain and sent only to the provider you pick. Add a model that ships before the app updates in models.json.

You set the leash

See the diff before it lands.

Croo shows each edit and each command before it runs, and works quietly in between. A run of tool calls folds into one line, so you can follow a long task without reading every step.

  • Manual asks before every action
  • Auto reads, edits and runs safe commands, and asks about the rest
  • Bypass never asks, for when you trust the plan
  • Plan researches first and changes nothing until you approve
  • Undo a turn’s file changes in one click

Chat mode

Not everything is code.

Chat mode is a plain conversation that remembers what you tell it. Ask for the weather, a route, a calculation or a chart and the answer arrives as a card, drawn by the app instead of described in prose.

  • Weather, places, routes, live flights, units and clocks
  • Charts from numbers in the conversation
  • Reads web pages and shows the sources it used
  • Memory you can read, edit and switch off

And the rest

Everything for working on code, in one calm window.

Git, built in
Inline diffs for every change, pick what to commit, and push. AI-written commit messages, and one click to publish a new repo to GitHub.
Run it from the chat
Shell, Python and Node snippets get a Run button. Output streams in under the code with the exit code and timing.
Terminal, files, browser
A real shell, a file tree with a viewer, and a small browser for previewing what you build, all beside the chat.
See it think
Reasoning streams into a row you can open. A clock, token count and cost estimate run while it works.
Attach, mention, speak
Paste screenshots, drop files, type @ to pull in a file, or dictate with the mic. Speech is transcribed on your Mac.
Find anything
⌘K searches chats by what was said, files by name, and actions. Edit any message and resend.
Hooks, skills, MCP
Run your own commands around tool calls, load skills from your folder, and plug in MCP servers. Project AGENTS.md and CLAUDE.md are read automatically.
Long tasks stay on track
Old messages are summarized before the context fills, a pinned task list shows progress, and a queue holds what you type while it works.

Install from Terminal

Recommended

One line installs the latest Croo into Applications and opens it. Croo isn’t notarized by Apple yet, and this way skips the “damaged app” warning that browser downloads get.

$ curl -fsSL https://ai.crooli.com/install.sh | bash

Download the app

A disk image for Apple Silicon Macs. If macOS says Croo is “damaged” after opening it, it isn’t: run xattr -cr /Applications/Croo.app once.

Build from source

Needs Node 20 or later. Builds the same app the releases ship.

$ git clone https://github.com/xandertaylorx/croo && cd croo && npm i && npm run dist
